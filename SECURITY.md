# Security policy

If you believe you have found a security vulnerability in Investminder, please report it
privately through GitHub: go to the
[Security tab of this repository](https://github.com/investminder/.github/security/advisories/new)
and click **Report a vulnerability**. Please do not open a public issue.

Include a description of the issue, the steps to reproduce it and its potential impact.
We will acknowledge valid reports and keep you informed of our progress.

Investminder does not run a paid bug bounty program.
